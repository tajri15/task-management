# Frontend (ReactJS)

Ini adalah antarmuka (UI) frontend untuk aplikasi Task Management, dibuat menggunakan React dan Vite.

## Cara Menjalankan

1.  Pastikan Anda memiliki Node.js dan npm terinstal.
2.  Masuk ke direktori `frontend`: `cd frontend`
3.  Install dependensi Node.js: `npm install`
4.  Pastikan server backend sudah berjalan di port 8000.
5.  Jalankan server frontend (Vite): `npm run dev`

Server akan berjalan di `http://localhost:5173` (atau port lain yang tersedia).
